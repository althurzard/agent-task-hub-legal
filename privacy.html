Agent Task Hub Backup

Privacy Policy

Last updated: October 5, 2026

Purpose

Agent Task Hub Backup is used by the deployment owner to store scheduled backups of a self-hosted Agent Task Hub instance in that owner's Google Drive account.

Google Drive access

The integration uses the Google Drive drive.file scope. It can create, read, update, and delete only the files and folders it uses for backups. It does not request permission to browse or manage unrelated files in the owner's Google Drive.

Data handled

Each backup can include the Agent Task Hub SQLite database and uploaded artifacts from the self-hosted deployment. The content is transferred directly from the owner's local Docker environment to the owner's Google Drive account.

Retention and sharing

Successful backups are removed from the dedicated backup folder after seven days. The integration does not sell, share, or use backup content for advertising, analytics, or any purpose other than backup and recovery.

Controls

The owner can stop backups, delete backup files, or revoke the Google Drive authorization at any time through their local deployment or Google Account permissions.
